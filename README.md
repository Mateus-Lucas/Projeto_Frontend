# Projeto: Cadastro e Visualização de Dados da Champions League

Este projeto foi desenvolvido para gerenciar e exibir informações sobre jogadores, times e estatísticas da UEFA Champions League. A interface moderna e intuitiva apresenta os dados por meio de cards dinâmicos e gráficos interativos, proporcionando uma experiência visual rica e envolvente.

Os usuários podem explorar detalhes sobre equipes, desempenho de jogadores, classificações e estatísticas da competição, tornando a análise mais acessível e atraente.

## 🚀 Como rodar o projeto localmente

### ✅ Pré-requisitos

Certifique-se de ter instalado:

- [Node.js (versão LTS recomendada)](https://nodejs.org)
- [npm](https://www.npmjs.com/) (já incluso com o Node.js)

### 📦 Instalação

```bash
# 1. Clone o repositório:
git clone https://github.com/Mateus-Lucas/Projeto_Frontend.git
cd Projeto_Frontend

# 2. Configure as variáveis de ambiente:
cp .env.local.example .env.local
# Depois de copiar, insira suas credenciais do Firebase no novo arquivo `.env.local`.

# 3. Instale as dependências:
npm install

# 4. Inicie o servidor de desenvolvimento:
npm run dev

# 5. Acesse no navegador:
http://localhost:3000
