Projeto: Cadastro e Visualização de Dados da Champions League

Este projeto foi desenvolvido para gerenciar e exibir informações sobre jogadores, times e estatísticas da UEFA Champions League. A interface moderna e intuitiva apresenta os dados por meio de cards dinâmicos e gráficos interativos, proporcionando uma experiência visual rica e envolvente.

Os usuários podem explorar detalhes sobre equipes, desempenho de jogadores, classificações e estatísticas da competição, tornando a análise mais acessível e atraente.
